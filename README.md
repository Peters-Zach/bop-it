# Bop It!

Spellbook-themed Bop It game for ECE 1895 Junior Design.

- `docs/` - Project proposal and notes.
- `firmware/` - Book and wand code.
- `hardware/` - Schematics and PCB files.
- `mechanical/` - Enclosure and CAD files.

[Basic prototyping pinout](hardware/prototype-pinout.md) - XIAO ESP32S3 wiring for both the book and wand, using the OneDrive BOM parts and available divider resistors.
