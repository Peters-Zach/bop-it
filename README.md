# Bop It!

Spellbook-themed Bop It game for ECE 1895 Junior Design.

- [Book firmware](firmware/book/README.md) - Larger ESP32-S3-DevKitC-1; separate DFPlayer, SPI OLED, and Hall sensor tests.
- [Wand firmware](firmware/wand/README.md) - Seeed XIAO ESP32-S3; separate force-sensor, IMU, and haptic tests.
- [Earlier LED exercises](firmware/hello_world/) - `One_LED` and `Three_LEDs`, retained as older ATmega exercises.
- [Project documents](docs/) - Proposal and notes.
- [Hardware](hardware/) - Schematics and PCB files.
- [Mechanical](mechanical/) - Enclosure and CAD files.

[Basic prototyping pinout](hardware/prototype-pinout.md) - Current DevKitC book and XIAO wand wiring, with the superseded XIAO book plan marked as historical reference.
